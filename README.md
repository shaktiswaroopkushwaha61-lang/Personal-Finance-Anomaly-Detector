# Personal Finance Anomaly Detector

A Java-based personal finance application that allows users to record transactions, analyze spending, generate financial summaries, and detect unusually high expenses.

## Features

- Add and store financial transactions
- View all recorded transactions
- Analyze spending by category
- Detect potentially unusual expenses
- Calculate total spending
- Calculate average transaction amount
- Simple menu-driven console interface

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming (OOP)
- Loops and Conditional Statements
- Switch-Case
- Java Collections

## How It Works

The application provides a menu with different options:

1. Add Transaction
2. View Transactions
3. Analyze Spending
4. Detect Anomalies
5. Financial Summary
6. Exit

Transactions contain information such as:

- Amount
- Category
- Date
- Description

The application stores transactions using Java's `ArrayList` and processes them using loops and conditional logic.

## Anomaly Detection

The application checks transactions based on the selected category and identifies transactions where the amount exceeds a predefined threshold.
